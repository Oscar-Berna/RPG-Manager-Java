# RPG Manager - Java

## Descripcion
Aplicacion de consola con arquitectura MVC conectada a MySQL.

## Requisitos
- Java JDK 25
- NetBeans
- XAMPP con MySQL corriendo
- mysql-connector-j-9.7.0.jar en el classpath

## Base de datos
- Abrir XAMPP y iniciar MySQL
- Crear base de datos: rpg_manager
- Ejecutar db/schema.sql en phpMyAdmin

## Ejecucion
- Abrir proyecto en NetBeans
- Ejecutar con F6

## Credenciales BD
- Host: 127.0.0.1
- Puerto: 3306
- Usuario: root
- Password: (vacio)
- Base de datos: rpg_manager
